# Ledger

> [!IMPORTANT]
> 这是 Ledger 当前用户指南，描述已提交实现中的用户行为。若本文与运行时行为发生偏差，以代码和 [Ledger Architecture](../architecture/ledger.md) 为准；旧 PRD 只保留设计沿革。

## Ledger 是什么

Ledger 是 Docus 内置的个人财务账本，用来回答“我现在有多少钱、欠多少钱、钱放在哪里，以及最近发生了什么”。它和三个 Workspace 的分工是：

~~~text
Note   → 我知道什么
Diary  → 我经历了什么
Ledger → 我的钱发生了什么
~~~

Ledger 不是银行聚合器，也不是专业会计系统。

## 进入 Ledger

当前入口是：

- /ledger：财务概览。
- /ledger/transactions：交易记录。
- /ledger/accounts：账户管理。
- /ledger/accounts/:id：账户详情。

旧的 /bills 和 /bills/transactions 只保留兼容重定向，会分别转到概览和交易记录，不是新的产品名称。

## 首次设置

第一次进入时依次完成：

1. 选择基础货币。
2. 选择 Ledger 使用的 IANA 时区。
3. 创建第一个账户。

第一个账户成功创建后，系统将 hasCreatedAccount 设为 true，基础货币和时区进入生命周期锁定状态；账户图标偏好仍可维护。金额按基础货币的小数位保存和显示。

## 账户

账户性质只有两种：

- asset（资产）：我拥有或控制的资金。
- liability（负债）：我需要偿还的债务。

账户类型包括现金、银行账户、钱包、信用卡、贷款和其他。现金、银行账户、钱包固定为资产；信用卡、贷款固定为负债；“其他”可以选择性质。

账户支持名称、性质、类型、图标、卡号、期初余额、期初日期和备注。当前余额由期初余额和有效交易实时投影得出，不是手工填写的字段。账户有交易历史后，性质、类型、期初余额和期初日期不能修改；账户资料字段仍按表单允许调整。

账户当前余额必须为 0 才能归档。归档账户仍可查看并可恢复，不能用于新的财务操作；有历史记录的账户不能永久删除。交易详情中若关联了归档账户，恢复账户后才能修改财务字段或删除交易。卡号在详情中以脱敏形式展示。

账户图标提供通用图标、中国主要银行、微信、支付宝、云闪付和自定义图标；自定义图标只改变展示，不改变账户语义。

## 分类

设置中的分类按“收入分类”和“支出分类”分组。普通分类可以创建、修改名称、替换图标和归档；分类名称在同一收支方向内不能重复。分类图标支持内置图标，也支持上传合法 SVG（不超过 256 KB 且不能包含脚本）。

设置页底部的“已归档分类”默认折叠，里面的分类仍可恢复，也可以尝试永久删除。永久删除只对没有交易历史的分类成功；有历史记录时服务端会拒绝删除，分类继续保持归档。

“利息”和“手续费”是受保护的支出系统分类。它们由还款和提现组合交易自动使用，不能按普通分类重命名、归档或删除；还款表单不要求用户再次选择“利息分类”。

## 记录一笔交易

顶层交易类型保持为：

- 收入：金额、账户、收入分类、发生时间、地点、交易对象和备注。
- 支出：金额、账户、支出分类、发生时间、地点、交易对象和备注。
- 转账：在两个账户之间移动资金。

### 转账子类型

转账内部有三个业务子类型，但它们不是新的顶层交易类型：

- **普通转账**：资产或负债账户之间的资金移动，不计入收入或支出。
- **还款**：资产账户 → 负债账户。表单中的本金是转账本金；可选利息会自动作为“利息”支出计入收支。
- **提现**：资产账户 → 资产账户。表单中的提现金额是资金移动金额；可选手续费会自动作为“手续费”支出计入收支。

还款例如本金 ¥5,000、利息 ¥300：资产账户减少 ¥5,300，负债减少 ¥5,000，本期支出增加 ¥300。提现例如 ¥2,000、手续费 ¥2：

- 额外扣除：转出减少 ¥2,002，转入增加 ¥2,000，支出 ¥2。
- 从提现金额中扣除：转出减少 ¥2,000，转入增加 ¥1,998，支出 ¥2。

因此利息和手续费不会被偷偷加进转账本金。

## 交易记录

交易记录以桌面数据表格呈现，列为：交易、类型、分类、账户、备注、时间和金额。还款、提现在类型列显示为转账的展示标签，分别显示“还款”和“提现”。

可按类型、账户、分类、日期和搜索条件筛选。日期支持全部、今天、本周、本月、今年和自定义范围；时间按 Ledger 时区解释，表格显示完整年份和时间。列表使用服务端分页，当前 UI 提供 5、25、50、100 条/页，不是无限滚动。

## 交易详情、编辑与删除

点击交易行可打开详情。普通收入、支出和转账可以编辑；删除是软删除，删除后不会再参与余额和汇总，也没有普通恢复入口。余额调整由账户调整流程维护，在交易详情中只读。

还款或提现的利息/手续费在产品层随同一笔操作展示，不作为普通独立行暴露。编辑或删除组合操作时，相关本金与附加支出保持同步。

## 财务概览

概览展示总资产、总负债、净资产、收支、账户、分类分析、最近交易、期间摘要和趋势。期间导航支持今天、本周、本月和今年，也支持以过去日期为锚点查看对应期间；趋势展示锚点所在的连续 12 个日历月。转账本金不进入收支统计，利息和手续费支出会进入支出及分类统计。

## 数据持久化与恢复

Ledger 记录持久化在 SQLite；余额、收支和图表数据都可由有效记录重新投影。新建设置、账户、分类和交易时，客户端会保存待确认意图并使用同一个幂等键重试；当请求结果不明确时，Ledger 会先要求恢复或确认，避免重复记账。页面刷新或服务重新启动后，已落库数据仍由服务端重新计算。
